# Gerenciamento de Anúncios

Este documento explica como usar o sistema de gerenciamento de anúncios do blog.

## Estrutura do Sistema

O sistema de anúncios permite criar anúncios de produtos afiliados que serão exibidos no blog. Cada anúncio possui:

- Título
- Imagem
- Link para o produto (Mercado Livre, Shopee, etc.)
- Categoria (associada aos temas do blog)
- Marcação de destaque

## Criando um Novo Anúncio

1. Acesse o painel de administração (`/admin`)
2. Clique em "Gerenciar Anúncios"
3. Clique no botão "Novo Anúncio"
4. Preencha os campos:
   - **Título**: Nome do produto
   - **URL da Imagem**: Link direto para a imagem do produto
   - **URL do Produto**: Link para o produto no Mercado Livre, Shopee, etc.
   - **Categoria**: Selecione a categoria apropriada
   - **Anúncio em Destaque**: Marque se desejar que o anúncio apareça na seção de destaques
5. Clique em "Salvar Anúncio"

## Editando um Anúncio

1. Acesse o painel de administração (`/admin`)
2. Clique em "Gerenciar Anúncios"
3. Na lista de anúncios, clique em "Editar" ao lado do anúncio desejado
4. Faça as alterações necessárias
5. Clique em "Salvar Anúncio"

## Visualizando Anúncios no Blog

Os anúncios são exibidos em várias seções do blog:

1. **Carrossel de Últimos Anúncios**: Na página principal
2. **Anúncios em Destaque**: Na página principal (2 anúncios)
3. **Anúncios por Categoria**: Em cada seção temática

## Categorias Disponíveis

- Suplementos Naturais
- Fitness e Emagrecimento
- Cuidados com o Corpo
- Alimentação Saudável

## Boas Práticas

1. **Imagens**: Use imagens de alta qualidade no formato 16:9
2. **Links**: Certifique-se de que os links para os produtos estão corretos
3. **Categorias**: Associe os anúncios às categorias apropriadas para melhor relevância
4. **Destaques**: Use a marcação de destaque com moderação para manter a eficácia
